# Security Policy

## Reporting Vulnerabilities

Please do not open public issues for suspected vulnerabilities.

Send a private report to the project maintainers with:

- affected component or endpoint;
- reproduction steps;
- expected impact;
- suggested fix, if known.

The maintainers will acknowledge reports as soon as practical and coordinate a fix before public disclosure.

## Secret Handling

Never commit real credentials, tokens, private keys, domains, production IPs, or provider account details. Use the example files as templates and provide real values through environment variables or a secret manager.
