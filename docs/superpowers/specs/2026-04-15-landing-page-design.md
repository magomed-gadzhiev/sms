# Landing Page + Pricing + SEO — Публичный сайт SMS-платформы

**Дата:** 2026-04-15
**Статус:** Draft

---

## 1. Контекст и проблема

SMS-платформа (PaaS для реселлеров) не имеет публичной входной точки. Все 27+ страниц портала находятся за авторизацией. Клиенты не могут узнать о платформе, изучить возможности и тарифы без предварительной регистрации.

## 2. Целевая аудитория

**Реселлеры** — SMS-агрегаторы и партнёры, которые приходят со своими провайдерами и ценами. Платформа предоставляет инфраструктуру (PaaS), а не трафик. Акцент на технические возможности системы.

## 3. Монетизация

Гибридная модель: базовая подписка + pay-per-use за объём сверх лимита.

### Тарифные планы

**Starter** — для начинающих реселлеров:
- До 50K SMS/мес включено
- 1 sub-account
- 3 провайдера
- API + веб-панель
- Email-поддержка

**Business** (основной) — для растущего бизнеса:
- До 500K SMS/мес включено
- 20 sub-accounts
- 10 провайдеров
- Маршрутизация по правилам
- Каскадная доставка
- Кампании и шаблоны
- Аналитика + экспорт
- Приоритетная поддержка

**Enterprise** — для крупных агрегаторов:
- Безлимит SMS
- Безлимит sub-accounts и провайдеров
- Все функции Business
- SMPP-доступ
- HLR-lookup
- SLA + выделенный менеджер
- Кастомная интеграция

Конкретные цены определяются позже (placeholder $XX/мес).

## 4. Архитектура

### Подход: SPA-маршруты в React Router

Публичные страницы реализуются внутри существующего проекта portal-frontend. Два layout-а в одном приложении:

```
PublicLayout (без sidebar, без auth)
├── /                  → Landing (hero + фичи + CTA)
├── /pricing           → Тарифные планы
├── /features          → Подробно о возможностях
├── /docs              → API документация
├── /blog              → Блог (список статей)
├── /blog/:slug        → Страница статьи
├── /about             → О компании
├── /contact           → Форма обратной связи
├── /docs/:slug        → Страница документации
├── /en/...            → Английские версии всех страниц

UserLayout (существующий, с auth)
├── /login
├── /register
├── /dashboard
└── ... (все текущие страницы портала)
```

## 5. Страницы

### 5.1. Главная страница (Landing)

7 секций сверху вниз:

**Секция 1 — Hero:**
- Заголовок: ключевое сообщение о PaaS для SMS-бизнеса
- Подзаголовок: 1-2 предложения о возможностях
- 2 CTA-кнопки: "Начать бесплатно" (→ /register) и "Документация API" (→ /docs)
- Фоновый градиент (фиолетовый, стиль Modern Gradient)

**Секция 2 — Social Proof:**
- 4 метрики: объём SMS/мес, uptime %, кол-во провайдеров, кол-во реселлеров
- Значения — placeholder-ы, обновляются вручную

**Секция 3 — Ключевые возможности:**
- 6 карточек (Lucide-иконка + заголовок + 2 строки описания):
  1. Свои провайдеры (SMPP, HTTP)
  2. Multi-tenant / Sub-accounts
  3. Маршрутизация по правилам
  4. Аналитика и детализация
  5. Биллинг и тарификация
  6. API & Webhooks
- Grid 3x2

**Секция 4 — Как это работает:**
- 3 шага с нумерацией:
  1. Регистрация — создайте аккаунт и настройте компанию
  2. Подключите провайдеров — SMPP или HTTP
  3. Отправляйте — API, веб-панель или SMPP

**Секция 5 — Скриншот платформы:**
- Заголовок + изображение дашборда портала
- Placeholder-изображение, заменяется реальным скриншотом

**Секция 6 — Тарифы (превью):**
- 3 карточки планов (Starter / Business / Enterprise) с ключевыми параметрами
- Business выделен как "Популярный"
- Ссылка "Подробнее о тарифах →" → /pricing

**Секция 7 — Финальный CTA:**
- Заголовок: "Запустите свой SMS-бизнес за 10 минут"
- Кнопка "Создать аккаунт бесплатно" → /register
- Фоновый градиент

**Footer:**
- 4 колонки: Продукт, Компания, Правовое, Поддержка
- Ссылки на все страницы + Telegram, Email
- Копирайт

### 5.2. Pricing

- Hero-секция с заголовком
- 3 карточки планов (полная информация: цена, лимиты, список фич)
- Таблица сравнения фич (все 3 плана рядом, галочки/крестики)
- Секция FAQ по тарифам:
  - "Что если превышу лимит?"
  - "Как перейти на другой план?"
  - "Есть ли пробный период?"
  - "Как происходит оплата?"
- Калькулятор сверхлимита: выбор объёма → примерная стоимость. Ставка за SMS сверх лимита задаётся в конфиге (i18n JSON), не требует backend-а
- CTA внизу

### 5.3. Features

- Hero-секция: "Всё для SMS-бизнеса"
- 10 блоков фич (чередование: текст слева/скриншот справа):
  1. Подключение провайдеров — SMPP и HTTP, мониторинг соединений
  2. Multi-tenant / Sub-accounts — клиенты, тарифы, балансы
  3. Маршрутизация — правила по стране, оператору, стоимости
  4. Каскадная доставка — SMS → мессенджеры, автоматический fallback
  5. Кампании и рассылки — массовая отправка, шаблоны, расписание
  6. API и интеграции — REST API, Webhooks, SMPP
  7. Аналитика и детализация — дашборд, экспорт отчётов
  8. Биллинг и тарификация — тарифы по направлениям, транзакции
  9. Sender Names — управление именами, статусы регистрации
  10. HLR-Lookup — проверка номеров, экономия
- Каждый блок: иконка (Lucide), заголовок, описание (3-4 предложения), placeholder для скриншота
- CTA внизу

- Миссия компании (1-2 абзаца)

## 6. Визуальный стиль

**Направление: Modern Gradient**

- Яркие градиенты (фиолетовый спектр: #312e81 → #4f46e5 → #7c3aed)
- Rounded-элементы (border-radius: 12-20px)
- Светлые секции чередуются с градиентными
- Кнопки: primary — белый текст на градиенте или белый фон с фиолетовым текстом
- Шрифт: системный стек (Inter, если будет подключен)
- Иконки: Lucide Icons (React-компоненты)
- Скриншоты: placeholder-изображения, заменяются реальными
- Адаптивность: mobile-first, breakpoints — sm (640px), md (768px), lg (1024px), xl (1280px)

## 7. Интернационализация (i18n)

- Библиотека: **react-i18next**
- Языки: RU (основной), EN (переключатель)
- URL-схема: `/pricing` (RU) → `/en/pricing` (EN)
- Тексты: `i18n/ru.json`, `i18n/en.json`
- Язык сохраняется в localStorage
- `<html lang="ru|en">` — переключается динамически
- Hreflang-теги: `<link rel="alternate" hreflang="en" href="/en/..." />`

## 8. SEO

- **react-helmet-async** для каждой публичной страницы:
  - `<title>`, `<meta name="description">`
  - Open Graph: og:title, og:description, og:image, og:url
  - JSON-LD structured data: Organization, Product, FAQ (для pricing)
  - Canonical URL
- **vite-plugin-prerender** — генерация статичного HTML для краулеров при билде
- **robots.txt** — разрешить публичные, запретить /dashboard, /messages и т.д.
- **sitemap.xml** — автогенерация списка публичных маршрутов
- Публичные страницы — индексируются
- Портал (/dashboard, /messages, ...) — `noindex, nofollow`

### Prerender-маршруты:
```
/  /pricing  /features  /docs  /about  /contact  /blog
/en  /en/pricing  /en/features  /en/docs  /en/about  /en/contact  /en/blog
```

## 10. Backend-изменения

- **POST /api/v1/contact** — приём формы обратной связи (имя, email, компания, сообщение), отправка уведомления на email администратора
- Никаких других backend-изменений не требуется

## 11. Вне скоупа

- Авторизация через соцсети
- Онлайн-чат / виджет поддержки
- A/B тестирование
- Аналитика посещений (Google Analytics и т.п. — можно добавить позже)
- Автоматическая генерация API-документации из кода (swagger/openapi)
- CRM-интеграция для формы контактов
