# Редизайн клиентской страницы "Сообщения"

**Дата:** 2026-04-14
**Подход:** Новый компонент с нуля (подход B)

## Суть

Объединяем два клиентских раздела — "Сообщения" (`/messages`) и "Детализация" (`/detalization`) — в один раздел **"Сообщения"** (`/messages`). Старые страницы удаляются. Новый раздел — это расширенная детализация трафика с продвинутыми фильтрами, настраиваемой таблицей и экспортом.

Функционал отправки SMS из старого раздела "Сообщения" не переносится.

---

## 1. Навигация и маршрутизация

### Маршруты

| Действие | Маршрут |
|----------|---------|
| Удалить | `/messages` (старый MessagesPage) |
| Удалить | `/detalization` (старый DetalizationPage) |
| Создать | `/messages` → новый компонент `MessagesPage` |
| Оставить | `/messages/:id` → существующий `MessageDetailPage` |

### Сайдбар (группа "Отследить")

Было:
- Сообщения → `/messages`
- Детализация → `/detalization`
- История каскадов → `/cascade/history`

Стало:
- Сообщения → `/messages`
- История каскадов → `/cascade/history`

### Заголовок страницы

**"Сообщения"** — основной заголовок.
**"Детализация трафика по всем клиентам и каналам"** — подзаголовок (text-muted).

---

## 2. Фильтры

### Основные фильтры (всегда видны)

| Фильтр | Тип | Описание |
|--------|-----|----------|
| Дата от | Date input | Начало диапазона |
| Дата до | Date input | Конец диапазона |
| Номер | Текстовый поиск | Поиск по номеру получателя |
| Логин | Текстовый поиск | Поиск по суб-аккаунту |
| Статус | Select/dropdown | pending, queued, sent, delivered, failed, expired, rejected, scheduled |
| Оператор | Select/dropdown | Оператор абонента (МТС, Билайн и т.д.), загружается с бэкенда |
| Имя отправителя | Select/dropdown | sender_name клиента, загружается с бэкенда |
| Канал | Select/dropdown | SMS, MAX, Viber |

### Дополнительные фильтры (сворачиваемый блок, скрыт по умолчанию)

| Фильтр | Тип | Описание |
|--------|-----|----------|
| ID сообщения | Текстовый поиск | Поиск по message_id |
| Способ отправки | Select/dropdown | ЛК, API, SMPP |
| Страна | Select/dropdown | Страна абонента, загружается с бэкенда |

### Поведение фильтров

- **Кнопка "Найти"** — применяет все фильтры разом (не auto-apply при изменении)
- **Кнопка "Сбросить"** — очищает все фильтры и перезагружает таблицу
- **Чипсы активных фильтров** — отображаются под блоком фильтров. Каждый чипс показывает название фильтра и значение, имеет крестик для удаления. При удалении чипса фильтр сбрасывается и таблица обновляется автоматически.

## 3. Таблица

### Столбцы по умолчанию

| Столбец | Данные | Сортировка |
|---------|--------|------------|
| Логин | Суб-аккаунт | нет |
| Номер телефона | destination | нет |
| Оператор | Оператор абонента | нет |
| Канал | SMS / MAX / Viber | нет |
| Текст сообщения | Обрезанный preview | нет |
| Дата отправки | submitted_at | да |
| Статус | Цветной бейдж | нет |
| Стоимость | total_amount, ₽ | да |

### Дополнительные столбцы (через "Настройка таблицы")

| Столбец | Данные | Сортировка |
|---------|--------|------------|
| ID | message_id | нет |
| Имя отправителя | source / sender_name | нет |
| Дата создания | created_at | да |
| Дата статуса | delivered_at / failed_at | да |
| Сегменты | segment_count | да |
| Провайдер | provider_name | нет |
| Страна | Страна абонента | нет |
| Способ отправки | ЛК / API / SMPP | нет |

### Сортировка

- Кликабельные заголовки для столбцов с пометкой "да" (только для видимых столбцов)
- По умолчанию: дата отправки, desc (новые сверху)
- Индикатор направления сортировки (стрелка вверх/вниз)

### Настройка таблицы

- Кнопка "Настройка таблицы" открывает dropdown/popover с чекбоксами
- Выбор столбцов сохраняется в localStorage
- Дефолтные столбцы отмечены при первом заходе

### Пагинация

- По умолчанию: 20 строк на страницу
- Селектор: 20 / 50 / 100
- Навигация: предыдущая / следующая / номера страниц

### Заголовок таблицы

- **"Найдено: n сообщений"** — количество по текущим фильтрам
- **Кнопка "Экспорт"** — рядом с количеством
- **Кнопка "Настройка таблицы"** — рядом с экспортом

### Клик по строке

Открывает модалку с кратким обзором сообщения.

---

## 4. Модалка (краткий обзор)

Открывается по клику на строку таблицы. Содержит основную информацию:

| Поле | Данные |
|------|--------|
| ID | message_id (полный) |
| Статус | Цветной бейдж |
| Отправитель | sender_name |
| Получатель | Номер телефона |
| Оператор | Оператор абонента |
| Канал | SMS / MAX / Viber |
| Текст сообщения | Полный текст |
| Дата отправки | submitted_at |
| Стоимость | total_amount, ₽ |

### Действия

- **"Подробнее"** — переход на `/messages/:id` (полная детальная страница)
- **Крестик** — закрытие модалки

### Доступ к детальной странице

Из двух мест:
1. Кнопка "Подробнее" в модалке
2. Иконка-ссылка в столбце действий таблицы (переход без открытия модалки)

---

## 5. Экспорт

- **Формат:** CSV
- **Кнопка:** В заголовке таблицы рядом с "Найдено: n сообщений"
- **Механизм:** Polling-based job (переиспользуем существующий из старого `/messages`)
- **Индикатор:** Спиннер/прогресс на кнопке пока файл готовится
- **Фильтры:** Экспорт учитывает текущие активные фильтры
- **Столбцы:** Все доступные поля независимо от настройки видимых столбцов:
  ID, Логин, Отправитель, Номер, Оператор, Канал, Статус, Текст, Дата создания, Дата отправки, Дата статуса, Сегменты, Стоимость, Провайдер, Страна, Способ отправки

## 6. Бэкенд-изменения

### Новые поля в ответе `/portal/v1/detalization`

Поля, которых сейчас нет и которые нужно добавить:

- `operator_name` — оператор абонента (определяется при маршрутизации по префиксу/MNP)
- `channel` — канал доставки (SMS / MAX / Viber)
- `login` — суб-аккаунт отправителя
- `country` — страна абонента
- `send_method` — способ отправки (ЛК / API / SMPP)

### Новые query-параметры фильтрации

- `login` — поиск по суб-аккаунту (like/partial match)
- `operator` — фильтр по оператору абонента
- `sender_name` — фильтр по имени отправителя
- `channel` — фильтр по каналу
- `country` — фильтр по стране
- `send_method` — фильтр по способу отправки
- `message_id` — поиск по ID сообщения

### Новые query-параметры сортировки

- `sort_by` — поле сортировки: `submitted_at`, `created_at`, `status_at`, `total_amount`, `segment_count`
- `sort_order` — направление: `asc` / `desc`

### Новые endpoint'ы справочников

- `GET /portal/v1/references/operators` — список операторов абонентов
- `GET /portal/v1/references/countries` — список стран

## 8. Архитектура компонентов (фронтенд)

```
pages/messages/
  MessagesPage.tsx          — новый основной компонент страницы
  MessageFilters.tsx        — компонент фильтров (основные + дополнительные)
  MessageTable.tsx          — таблица с настраиваемыми столбцами
  MessageModal.tsx          — модалка краткого обзора
  ColumnConfigurator.tsx    — настройка видимых столбцов
  ActiveFilterChips.tsx     — чипсы активных фильтров
  MessageDetailPage.tsx     — существующая детальная страница (без изменений)
```

Каждый компонент отвечает за одну задачу. Состояние фильтров и пагинации управляется в `MessagesPage` и пробрасывается через props.
