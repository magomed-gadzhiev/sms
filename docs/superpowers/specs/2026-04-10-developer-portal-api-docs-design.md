# Developer Portal / API Docs — Design Spec

**Date:** 2026-04-10
**Status:** Approved

## Goal

Lower the integration barrier for partners and clients by exposing interactive API documentation directly from the Client Gateway. No new services or ports required.

## URLs

| URL | Content |
|---|---|
| `GET /docs` | Redoc — human-readable REST API docs |
| `GET /docs/swagger` | Swagger UI — interactive REST API (Try it out) |
| `GET /docs/grpc` | Proto docs — gRPC service reference |
| `GET /docs/openapi.yaml` | Raw OpenAPI 3.0.3 spec |

All `/docs/*` routes are public — registered before `SessionAuthMiddleware`.

## Architecture

Client Gateway (Go + gorilla/mux) embeds static files via `//go:embed`. No new Docker services or HAProxy backends needed. Static files are baked into the binary at build time.

```
//go:embed static/docs static/openapi.yaml
var docsFS embed.FS
```

## File Structure

```
cmd/client-gateway/
  static/
    openapi.yaml              ← copied from api/openapi/openapi.yaml at build time
    docs/
      index.html              ← Redoc page
      swagger.html            ← Swagger UI page
      grpc.html               ← generated by protoc-gen-doc, committed to repo

internal/gateway/client/router/
  docs.go                     ← registers /docs/* routes (public, no auth)

scripts/
  gen-proto-docs.sh           ← runs protoc-gen-doc over all api/proto/**/*.proto

Makefile                      ← new targets: gen-proto-docs, copy-openapi
```

### `static/docs/swagger.html` — Swagger UI

Standard Swagger UI from CDN with `url: '/docs/openapi.yaml'` and Bearer token input field.

### `static/docs/grpc.html` — Proto docs

Generated by `protoc-gen-doc` using its built-in HTML template. Covers all `.proto` files under `api/proto/`. File is generated locally and committed — not generated in CI.

## Router Integration

New file `internal/gateway/client/router/docs.go`:

```go
func RegisterDocsRoutes(r *mux.Router, fs embed.FS) {
    r.PathPrefix("/docs/").Handler(http.FileServer(http.FS(fs)))
}
```

Called from the main router setup **before** `SessionAuthMiddleware` is applied.

## Build Process

```makefile
gen-proto-docs:
    bash scripts/gen-proto-docs.sh

copy-openapi:
    cp api/openapi/openapi.yaml cmd/client-gateway/static/openapi.yaml

build-client-gateway: gen-proto-docs copy-openapi
    go build ./cmd/client-gateway/...
```

### `scripts/gen-proto-docs.sh`

```bash
#!/bin/bash
set -e
protoc \
  --doc_out=cmd/client-gateway/static/docs \
  --doc_opt=html,grpc.html \
  --proto_path=api/proto \
  $(find api/proto -name "*.proto" | sort)
```

`protoc-gen-doc` is a local dev tool — not required in production builds since `grpc.html` is committed.

## Getting Started Content

Added as Markdown in `info.description` of `api/openapi/openapi.yaml`:

```yaml
info:
  description: |
    ## Getting Started

    1. Get an API key from the [client portal](http://72.56.232.202:8083)
    2. Add header: `Authorization: Bearer <your-api-key>`
    3. Base URL: `http://72.56.232.202:8080/api/v1`

    ### First request
    ```bash
    curl -X POST http://72.56.232.202:8080/api/v1/sms/send \
      -H "Authorization: Bearer YOUR_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{"phone": "+79001234567", "text": "Hello!"}'
    ```
```

Redoc renders `description` Markdown natively — no extra HTML page needed.

## No New Dependencies

- No new Go packages
- `protoc-gen-doc` is a local dev tool (`go install github.com/pseudomuto/protoc-gen-doc/cmd/protoc-gen-doc@latest`)
- Redoc and Swagger UI loaded from CDN (jsdelivr.net / unpkg.com)
