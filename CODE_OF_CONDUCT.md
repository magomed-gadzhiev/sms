# Code of Conduct

This project follows a simple standard: be respectful, constructive, and professional.

Participants are expected to:

- use welcoming and inclusive language;
- focus critique on ideas and code, not people;
- respect differing experience levels and backgrounds;
- avoid harassment, threats, insults, or private-information disclosure.

Maintainers may remove comments, issues, pull requests, or participation that violates these expectations.
